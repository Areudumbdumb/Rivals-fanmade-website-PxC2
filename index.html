🧪 What is this?

This is a fan-made interface inspired by the visual language of a competitive shooter lobby: bright floor lines, dark panels, status boards, giant buttons and fast menu navigation.

Important note

This website is a mock interface. It does not connect to Roblox servers or retrieve live Roblox player data.

🏗️ Who made it?

The concept, layout and code are a collaborative fan project made by Prateek × ChatGPT .

Project team

Prateek — creative direction, player ideas and testing. ChatGPT — coding, interface design and systems logic.

🛰️ Why the lobby style?

The design uses a futuristic hub approach with neon pathways, dark metallic surfaces, oversized status displays and compact menus.

Design reference

The visual direction was informed by publicly available screenshots of the game's lobby and hub areas.

🧠 Web tech inside

This single file uses CSS variables, responsive Grid, Canvas animation, localStorage, a persistent device ID, Supabase, dynamic DOM updates and a timed XP system.

Why one file?

Keeping everything in one HTML file makes the first version extremely easy to edit and publish.

🎯 No fake stats

The personal dashboard displays information the player actually entered. The profile score is derived from those values.

What is calculated?

Profile rating and personal level progress are calculated locally. Community XP unlock status is based on the shared profile count.

⚡ Built for expansion

Later versions can add challenge tracking, themes, map cards, cosmetics, match history and additional profile modules.

Future possibilities

The current backend architecture makes it possible to add more shared community systems later.

Timed XP Claim

Five scheduled claims, then the cycle restarts. XP activates only after the community reaches 6 profiles.
